Nội dung chính

Đây là khu vực nội dung chính của trang web. Bố cục được xây dựng bằng CSS Grid.

Trang web có khả năng responsive và hiển thị tốt trên cả máy tính và điện thoại.

CSS Grid giúp chúng ta dễ dàng sắp xếp các thành phần của trang web thành các hàng và cột.
